Threat Intel

Malware & Computer Viruses

🦠 Computer Virus

A specific form of malicious code that replicates by attaching copies of itself into other executable programs or files. It remains dormant until a user executes the infected host program.

⚠️ Computer Infection

The state where malicious code compromises system integrity, modifies boot sectors or system registries, establishes persistent background processes, or degrades operating performance.

🛡️ Malware (Malicious Software)

The umbrella classification for all intentionally hostile software designed to damage, hijack, or gain unauthorized access to computer systems, data, and networks.

Analysis: Virus vs. Malware

Criteria Computer Virus Malware (Broad Category)
Scope A single sub-category of malicious software. Comprehensive family covering all malicious threats.
Host Requirement Requires a legitimate host program or file to attach itself to. Can be standalone (Worm) or disguised (Trojan); host file not required.
Execution Method Requires human action to trigger (opening the infected program). Executes via network exploits, user actions, or automated scripts.
Relationship Every computer virus is classified as malware. Not all malware is a virus (e.g., Spyware, Ransomware, Trojans).

Malware Classification & Impact

🐛 Worm

Standalone malware capable of replicating across networks without human intervention or host file attachment, rapidly consuming bandwidth and exploiting open ports.

🎭 Trojan Horse

Malicious software masquerading as useful, legitimate software (such as utilities, games, or media players) to trick the user into executing it, silently dropping backdoors.

👁️ Spyware

Covert software that monitors user activities, records keystrokes (keylogger), logs internet browsing habits, and harvests passwords without user consent.

🔒 Ransomware

Extortion malware that encrypts high-value user files using strong cryptographic ciphers, rendering them inaccessible until an extortion fee (ransom) is paid.

🛡️
Protection Protocol: Deploy an active real-time antivirus engine, block untrusted executable downloads, isolate suspicious email attachments in sandbox environments, and maintain offline immutable file backups.
System Hardening

Personal Computer & Operating System Security

🎯 Importance of PC Security

Personal computers store sensitive credentials, private documents, and financial data. Securing endpoints prevents identity theft, data extortion, and unauthorized network pivot attacks.

🛡️ OS Security & Privilege Control

Enforce the Principle of Least Privilege. Use standard user accounts for everyday tasks and keep User Account Control (UAC) enabled to prevent silent administrative changes.

🔑 Strong Credential Management

Utilize 14+ character passphrases combining uppercase, lowercase, numbers, and symbols. Never reuse credentials across services, and activate Multi-Factor Authentication (MFA).

🔍 Security Software Deployment

Keep Windows Defender Antivirus or certified EDR security software running continuously. Ensure daily definition updates to recognize new threat signatures.

🌐 Safe Web Browsing Standards

Verify HTTPS encrypted connections, block intrusive third-party tracking scripts, avoid untrusted browser extensions, and heed browser SSL certificate warnings.

🚫 Avoiding Suspicious Files & Links

Verify file extensions (watch for hidden extensions like report.pdf.exe), disable automatic Office macros, and hover over hyperlink URLs before clicking.

🔒
Physical Endpoint Practice: Always lock your workstation session (press Win + L on Windows) when stepping away to prevent local unauthorized access.
Patch Management

Windows Update & Vulnerability Mitigation

⚙️ What Windows Update Is

An integrated OS maintenance service from Microsoft that distributes critical security patches, driver fixes, and stability improvements directly to your computer over encrypted channels.

🎯 Why Updates Are Essential

When security vulnerabilities (CVEs) are publicly discovered, threat actors weaponize them. Windows Update closes these vulnerabilities before exploits can compromise your system.

🩹 Security Patches vs Feature Updates

Security Patches: Resolve critical code vulnerabilities and zero-day exploits.
Feature Updates: Provide operating system upgrades and functionality revisions.

⚠️ Hazards of Outdated Software

Unpatched operating systems are vulnerable to remote code execution (RCE), privilege escalation, and automated worm attacks (such as WannaCry exploiting unpatched SMBv1 ports).

Standard Procedure: Checking for Windows Updates

  1. Press the Windows Key or open the Start Menu.
  2. Open Settings (or press Win + I).
  3. Select Windows Update (Windows 11) or Update & Security (Windows 10).
  4. Click the Check for updates button.
  5. Allow the system to download and install security patches, then restart if required.
⚠️
Vulnerability Window: Delaying updates after security patches are released leaves your device exposed to reverse-engineered exploits. Keep automated updates enabled!
Threat Defense

Cyber Attack Vectors & Defensive Countermeasures

🎣 Phishing Attacks

Social engineering attacks delivered through fraudulent emails, SMS (smishing), or cloned websites designed to trick targets into handing over login credentials or financial information.

💣 Malware Attacks

Deliberate distribution of malicious binaries through drive-by browser downloads, malicious USB devices, or infected torrent files to seize system command and control.

🔑 Password Attacks

Automated attempts to crack credentials using Brute Force (trying every permutation), Dictionary Attacks (testing common passwords), or Credential Stuffing from breached data.

👥 Social Engineering

Exploiting human psychology—such as urgency, trust, authority, or panic—to manipulate individuals into bypassing security safeguards or divulging confidential data.

🚫 Denial of Service (DoS)

Flooding target servers or network interfaces with overwhelming dummy traffic to exhaust network bandwidth and hardware resources, blocking legitimate user access.

🛡️ Defensive Countermeasures

Enforce Multi-Factor Authentication (MFA), deploy email spam filters, establish strong password complexity policies, and filter incoming traffic using firewalls.

Physical Security

Tailgating Attack: Physical Perimeter Breach

🚶 Definition

Tailgating (also known as Piggybacking) is a physical security breach where an unauthorized individual closely follows an authorized employee through a secured access door or barrier without presenting valid credentials.

🎭 Attack Mechanism

The intruder relies on human courtesy and social pressure. They may pretend to be in a rush, carry bulky items, dress as delivery staff, or feign a lost keycard to induce an employee into holding the door.

🏢 Scenario Example

An intruder wearing a fake courier uniform carrying a package approaches a restricted lab entrance just as an authorized engineer scans their access card. The engineer holds the door open out of politeness, letting the intruder enter without scanning.

⚠️ Critical Risks

Physical access renders software defenses vulnerable: an intruder can deploy hardware keyloggers, insert rogue USB payloads into workstations, steal paper documents, or tamper with networking equipment.

🛑
Prevention Controls: Install optical turnstiles or access mantraps, enforce a strict "One Badge, One Person" policy, train personnel to challenge unbadged individuals, and position security guard checkpoints at entries.
Audit & Assessment

Ethical Hacking & 7 Steps of Reconnaissance

⚖️ What Ethical Hacking Is

The practice of utilizing authorized penetration testing techniques to evaluate system security, uncover vulnerabilities, and report flaws to the organization for remediation before malicious actors exploit them.

🤝 Ethical vs Unauthorized Hacking

Ethical (White Hat): Authorized with written legal scope, responsible disclosure, defensive intent.
Unauthorized (Black Hat): Unauthorized, illegal access, malicious intent, data extortion or theft.

🎯 Defensive Purpose

To identify misconfigurations and patchable vulnerabilities proactively, test defensive detection readiness, validate compliance, and harden organizational resilience.

Defensive Methodology: 7 Steps of Reconnaissance

01 // RECON
Footprinting

Collecting publicly accessible target information (DNS records, WHOIS, public documents) passively without direct engagement.

02 // SCAN
Network Scanning

Pinging and checking live host availability across authorized IP ranges to discover active systems.

03 // PROBE
Port Scanning

Inspecting open TCP and UDP communication ports to assess potential communication entry points.

04 // IDENT
Service & Banner Grabbing

Interrogating open ports to determine service names and exact software versions for vulnerability correlation.

05 // PROFILE
OS Fingerprinting

Analyzing TCP/IP packet header signatures (TTL values, window sizes) to identify target operating systems.

06 // QUERY
Enumeration

Querying accessible resources such as network shares, user groups, and directories to identify exposed access points.

07 // REPORT
Vulnerability Analysis

Cross-referencing discovered service versions against CVE databases to compile actionable risk remediation reports.

⚖️
Legal Compliance Notice: Performing network scanning, port probing, or vulnerability assessments on systems without explicit written consent is illegal. This reconnaissance framework is strictly used for defensive auditing of authorized assets.
Perimeter Defense

Windows Firewall: Packet Filtering & Protection

🧱 What a Firewall Is

A network security system that inspects incoming and outgoing packet traffic and decides whether to permit or drop specific transmissions based on predetermined security filtering rules.

💡 Why a Firewall Is Essential

Without a firewall, any open network port on your operating system is exposed to external probes, worms, and unauthorized remote access attempts on the local subnet or internet.

🔄 Inbound vs Outbound Filtering

Inbound Traffic: Inspects packets sent to your device, blocking unsolicited connection probes.
Outbound Traffic: Monitors connections originating from your device, preventing malware from communicating with Command & Control servers.

💻 Windows Defender Firewall

Built-in stateful firewall providing tailored security profiles: Domain (work network), Private (trusted home network), and Public (untrusted airports/cafes with heightened inbound blocks).

⚙️ Basic Configuration Rules

Configuring rule-based port blocking, managing application access lists, and enabling logging to track dropped packet attempts.

✨ System Protection Benefits

Shields vulnerable system services from network exploitation, stops rogue background processes from leaking data, and prevents unauthorized port connections.
